# 09. 画面接触 + 想定ペン先指定（検証モード）

## 背景

最終構想は **手を画面に置いたまま** 直線を描くこと。  
カメラだけで掌接触姿勢を認識するのは難しいため、最初の検証は次の仮説で行う。

> ペンを握る形で手を画面に置き、ユーザーが「ここがペン先だ」と指定すれば、  
> その後の接触点の動きにオフセットを足して仮想ペン先を追従できるのではないか。

将来は、スクリーンが反応した接触領域（マルチタッチの分布）を学習し、  
接触パターンからペン先を推定する方向へ進める。

## 今回試す手順

1. 描画キャンバスに、ペンを握る形で手を置く
2. 反応している接触点（タッチ）を記録し、手の基準点（アンカー）とする
3. ユーザーが想定する仮想ペン先位置をタップして指定する
4. `offset = tip - anchor` を保存する
5. 手を動かすと `tip = currentAnchor + offset` で線を描く

## カメラ方式との関係

| 方式 | 役割 |
|---|---|
| 画面接触 + ペン先指定 | **本命仮説の第一検証**（iPad 向け） |
| カメラ landmark 推定 | 空中でも動く比較用ベースライン |

両方をアプリ内で切り替え可能にして比較する。

## 将来の機械学習への橋渡し

いま記録できるもの:

- 同時タッチ座標の集合（スクリーン反応部分）
- ユーザー指定のペン先
- 移動中の接触軌跡と描画軌跡

これらが、後で「接触パターン → ペン先」を学習する教師データの原型になる。
