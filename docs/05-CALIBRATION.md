# 05. キャリブレーション仕様

## 1. 方針

今回の条件は **「初回から完全にペンなし」**。  
Apple Pencil などで正解ペン先を与えない。

したがってキャリブレーションの目的は次に限定する。

- ユーザーの手の大きさ・握り方に合わせて **幾何パラメータを調整する**
- カメラ空間とキャンバス空間の **粗い対応づけ** を作る

「本当のペン先位置の教師あり学習」は、この段階では行わない。

## 2. 取得するパラメータ

| パラメータ | 意味 | 使い先 |
|---|---|---|
| \(L\) | 仮想ペン長 | 方式 C/D/E/F/G |
| \(O=(o_x,o_y)\) | 個人オフセット | 方式 G、または全方式共通後段 |
| scale / translate | 正規化→Canvas の写像 | CoordinateMapper |
| gripTemplate | 握り形の代表距離・角度 | GripDetector の基準 |
| reachableBounds | 操作中の手の可動範囲 | 写像のスケール決定 |

## 3. 初期キャリブレーションの流れ

ユーザー操作をできるだけ短くする（目標 20〜40 秒）。

### Step 0 — 準備

1. カメラを起動する
2. 照明が顔/手元を十分照らしていることを確認
3. カメラに利き手が映る位置に座る（机上に肘を置いてもよい）

### Step 1 — 握り形の固定（3〜5秒）

1. ペンを握るような手の形を作る
2. 画面中央あたりで静止
3. 連続フレームの landmark を収集し、中央値（または平均）を取る

記録例:

- \(d(4,8),\; d(8,12),\; d(0,G)\)
- 指の屈曲指標
- 代表 \(G\) と仮の \(v\)

### Step 2 — 微小運動（5〜10秒）

1. 握り形を維持したまま、左右・上下に小さく動かす
2. landmark 軌跡から可動範囲（min/max）を取得
3. 必要なら「画面の四隅付近まで動かして」とガイドする簡易版も用意

### Step 3 — 長さ L の仮決め

正解ペン先がないため、次のいずれかで仮決めする。

| 方法 | 内容 | 利点 | 欠点 |
|---|---|---|---|
| **固定初期値** | \(L = k \cdot \|G-P_{\mathrm{wrist}}\|\) | 実装が簡単 | 個人最適でない |
| **スライダ調整** | ユーザーが点の位置を見ながら L を合わせる | 直感的 | 主観依存 |
| **ターゲット合わせ（推奨）** | 画面上の目印にペン先点を重ねてもらう | オフセットも同時に取れる | 手順が少し増える |

#### 推奨: ターゲット合わせ（ペンなしのまま）

1. キャンバスに十字ターゲットを1つ出す
2. 「仮想ペン先の点を、この十字に重ねてください」と指示
3. ユーザーが手を動かし、重なったと感じたタイミングで確定ボタン
4. そのときの推定 \(P\) とターゲット \(T\) の差を \(O = T - P\) として保存
5. 任意でターゲットを2〜3箇所繰り返し、平均オフセット or 簡易 affine を作る

これは正解ペン先の学習ではなく、**ユーザー意図位置への合わせ込み**である。

### Step 4 — 完了

- パラメータをメモリ（任意で localStorage）に保存
- UI に「Calibrated」を表示
- いつでも再キャリブ可能

## 4. キャリブなしモード

実験5のため、次を必ず残す。

- **Calibration OFF**: デフォルト \(L\), \(O=(0,0)\), 単純スケール写像
- **Calibration ON**: 上記で得た値を使用

同一ユーザー・同一タスクで ON/OFF を比較する。

## 5. UX 文言案

```
1. ペンを握る形を作って、3秒静止してください
2. そのまま左右・上下にゆっくり動かしてください
3. 画面の十字に、緑の点（仮想ペン先）を重ねて [確定]
```

失敗時:

- 手が検出できない → 位置・照明を見直す
- ブレが大きい → もう一度静止ステップへ

## 7. やらないこと（明確化）

- Apple Pencil / マウスで正解軌跡を録って学習すること（今回は禁止ではないがスコープ外）
- 長時間のパーソナルモデル学習
- 複数セッションにまたがる自動再学習

まずは「短い手動キャリブで誤差が減るか」を実験5で確認する。
