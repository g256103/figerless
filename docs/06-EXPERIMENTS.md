# 06. 実験計画

この試作で最も重要なのは「線が引けたか」ではなく、  
**どの計算方法・補正方法が最も意図どおりに直線を引けるか**を比較すること。

## 0. 共通条件

実験ごとに可能な限り揃える。

| 項目 | 推奨固定値 |
|---|---|
| ブラウザ | Chrome 最新 |
| 解像度 | 1280×720 前後 |
| 照明 | 手元が影にならない昼光 or 室内灯 |
| 背景 | 手以外の動きが少ない無地に近い背景 |
| 距離 | カメラから腕が自然に映る距離（個人で記録） |
| 手数 | 利き手1本 |
| 試行回数 | 各条件 5〜10 回 |

各試行で記録する共通メタデータ:

- 日時、被験者ID（匿名可）、利き手
- estimationMode / smoothingMode / パラメータ
- calibration ON/OFF
- ガイド種類（水平/垂直/斜め）
- 成功/失敗、コメント（認識ロスト等）

## 実験1：手の動きが認識できるか

### 目的

カメラが手の動きを安定して取得できるか確認する。

### 内容

握り形を維持したまま、次を行う。

1. 静止（5秒）
2. 左右移動
3. 上下移動
4. 円を描くように動かす
5. 手首の角度を変える（回旋・掌屈/背屈の軽い変化）

### 評価

| 項目 | 測り方 |
|---|---|
| ランドマーク取得成功率 | 検出フレーム / 全フレーム |
| 位置ブレ | 静止時の \(P\) の標準偏差 |
| 認識不可条件 | 角度・速度・照明メモ |
| 追従速度 | 主観 1–5 + 可能なら遅延概算 |

### 合格の目安

- 静止〜並移動作で成功率 95% 以上
- 極端な回旋で落ちる条件を文書化できている

## 実験2：仮想ペン先を推定できるか

### 目的

手のどの部分を基準にすれば、意図した描画位置を再現しやすいか調べる。

### 比較方式

| 方式 | 計算 | 役割 |
|---|---|---|
| A | 人差し指先端 | ベースライン |
| B | 親指・人差し指の中間 | 握り位置 |
| C | 握り位置 + 手首方向延長 | 仮想ペン先（本命） |

余裕があれば D/E も同一プロトコルで追加。

### 内容

1. キャンバスにターゲット点（または短いガイド）を出す
2. 「仮想ペン先の点をターゲットに重ねる」操作を各方式で行う
3. 重ねやすさ・安定性を記録
4. 左右にゆっくり動かしたときの点の挙動を観察

### 評価

- ターゲット合わせの平均誤差
- 主観的な「意図との一致」（1–5）
- 握り形維持のしやすさ

## 実験3：直線を引く（最重要）

### 目的

推定した仮想ペン先が、意図した直線に追従するか確認する。

### 内容

1. キャンバスに薄い水平ガイドを表示
2. その線に沿って手を左→右へ動かす
3. 描画線とガイドを比較
4. 垂直・斜めでも同様に実施
5. 方式 A/B/C × 各方向で繰り返す

### 評価指標

| 指標 | 意味 | 計算の考え方 |
|---|---|---|
| 平均位置誤差 | ガイドからどれだけ離れたか | 各描画点とガイド線の距離の平均 |
| 最大位置誤差 | 最大ズレ | 距離の最大値 |
| 直線性 | 描いた線が直線に近いか | 回帰直線との残差 / 始終点距離比など |
| 遅延 | 手と描画の時間差 | 可能なら簡易計測。難しければ主観 |
| 成功率 | 最後まで線を引けた割合 | 認識ロスト・大幅逸脱なし |

すべて **同一 Canvas 座標系** で比較する。

### 暫定目標

- 完了率 90% 以上
- 平均位置誤差 ≤ 画面幅の 2%
- 3方向すべて描画可能

### 結果メモ

## 実験4：補正方法を比較する

### 目的

線のブレと遅延のバランスを改善する。

### 比較条件

- 補正なし
- EMA（α = 0.15 / 0.3 / 0.5 など）
- One Euro Filter（代表パラメータ2セット）

方式は実験2〜3で有望だったものを固定（例: C）。

### 評価

| 項目 | 視点 |
|---|---|
| 滑らかさ | ガタつきの少なさ |
| 遅延 | 手に対する遅れ |
| 角の再現 | 折り返しや方向転換での遅れ/オーバシュート |
| 直線誤差 | 実験3指標を再計測 |

「綺麗だが遅い」は不合格寄り。直線追従では遅延も重要。

### 結果メモ

|---|---|---|---|---|
| none |  |  |  |  |
| EMA 0.3 |  |  |  |  |
| One Euro |  |  |  |  |

## 実験5：個人差に対応できるか

### 目的

手の大きさや握り方が違うユーザーでも描画できるか確認する。

### 内容

複数人（最低2〜3人、可能なら5人）に同一タスク（実験3の水平線）を行ってもらう。

条件:

1. キャリブレーションなし
2. キャリブレーションあり

### 評価

- 平均位置誤差の個人間ばらつき
- キャリブによる改善量
- 「合わせやすさ」の主観

### 結果メモ

## 実験実施の順序（推奨）

```
実験1（認識の土台）
  → 実験2（方式の当たりをつける）
    → 実験3（直線で本評価）
      → 実験4（平滑化最適化）
        → 実験5（個人差）
```

実装が追いつかない場合の最小セット:

1. 実験1
2. 実験3（方式 A vs C だけ）
3. 実験4（none vs EMA）

## 計測実装の優先度

| 優先度 | 内容 |
|---|---|
| P0 | 目視比較 + 成功/失敗記録シート |
| P1 | ガイド線との点距離をコードで計算して画面表示 |
| P2 | 試行ごとの CSV / JSON エクスポート |
| P3 | 遅延の時刻同期計測 |

最初は P0+P1 で十分。数値が出た時点で方式の優劣をドキュメントへ反映する。
