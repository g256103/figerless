# 03. Web版 実装仕様

## 1. 使用技術

| 技術 | 用途 |
|---|---|
| HTML | 画面構造 |
| CSS | UI・レイアウト |
| JavaScript | カメラ制御・推定・描画・実験切替 |
| MediaPipe Hand Landmarker | 手の21 landmark 検出 |
| Canvas API | 線・ガイド・デバッグ描画 |
| getUserMedia | Web カメラ映像取得 |

独自学習は行わない。既存の手認識モデルの出力から幾何推定する。

## 2. 画面仕様

最初の試作画面はシンプルにする。情報は多いが、**操作は迷わない配置**にする。

### 2.1 必須 UI

| UI | 機能 | 備考 |
|---|---|---|
| カメラ映像 | 自分の手の動きを確認 | ミラー表示推奨。骨格オーバーレイ可 |
| 描画キャンバス | 線を描く領域 | ガイド線もここへ描く |
| カメラ開始 | Webカメラ起動 | 権限エラー表示あり |
| キャリブレーション | 基準姿勢・写像の取得 | [05-CALIBRATION.md](05-CALIBRATION.md) |
| 描画開始 / 停止 | 描画 ON/OFF | **ボタン操作（必須）** |
| 線を消去 | 軌跡リセット | ガイド線は残す/消すを選択可 |
| 座標表示 | 仮想ペン先の現在位置 | raw / smooth / canvas を区別表示 |

### 2.2 実験用 UI（強く推奨）

| UI | 機能 |
|---|---|
| 推定方式セレクト | A / B / C（＋拡張方式） |
| 平滑化セレクト | none / EMA / One Euro |
| パラメータスライダ | α, L, One Euro 係数など |
| ガイド線切替 | なし / 水平 / 垂直 / 斜め |
| Grip インジケータ | 握り形スコアの可視化 |
| FPS / 検出スコア | 性能と安定性の確認 |
| カーソル点 | 現在の \(P_{\mathrm{pen}}\) を小さな点で表示 |

### 2.3 レイアウト方針（提案）

```
┌──────────────────────────────────────────────┐
│ HandPen AI PoC          [方式C▼] [EMA▼] ... │
├────────────────────┬─────────────────────────┤
│                    │                         │
│   Camera + skeleton│     Drawing Canvas      │
│                    │     (+ guide line)      │
│                    │                         │
├────────────────────┴─────────────────────────┤
│ [カメラ開始] [キャリブ] [描画開始] [消去]     │
│ Pen: (x,y)  grip:0.82  fps:30  delay:~    │
└──────────────────────────────────────────────┘
```

モバイルでも一応動くことを妨げないが、**最初の実験対象はデスクトップ＋Webカメラ**とする。

## 3. 手の認識仕様

### 3.1 利用ランドマーク

MediaPipe Hands の 21 点のうち、特に次を使う。

| 部位 | ID | 利用目的 |
|---|---|---|
| 手首 | 0 | 手全体の位置・方向基準 |
| 親指先端 | 4 | 握り形・握り位置 |
| 人差し指付け根 (MCP) | 5 | 指の方向・姿勢 |
| 人差し指先端 | 8 | 握り位置・方式A |
| 中指付け根 (MCP) | 9 | 手の向き補助 |
| 中指先端 | 12 | 握り形補助 |

参考として、方式拡張では次も候補になる。

| 部位 | ID | 候補用途 |
|---|---|---|
| 人差し指 PIP | 6 | 屈曲による握り判定 |
| 中指 PIP | 10 | 同上 |
| 薬指/小指先端 | 16, 20 | 握り閉じ判定 |
| 中指/人差し指 DIP | 7, 11 | ペン軸近似の補助 |

### 3.2 検出設定（初期値案）

| 項目 | 初期値 | メモ |
|---|---|---|
| maxHands | 1 | 右手 or 利き手1本に固定 |
| minDetectionConfidence | 0.6 | 実験で調整 |
| minPresenceConfidence | 0.5 | 同上 |
| minTrackingConfidence | 0.5 | 同上 |
| runningMode | VIDEO | 連続フレーム |

左右どちらでも動くことを目指すが、実験ログには handedness を記録する。

### 3.3 認識失敗時の挙動

| 状況 | 描画中の挙動 |
|---|---|---|
| 手が消えた | 線を伸ばさない。現在パスを切る（次フレームは新ストローク開始） |
| スコア低下 | 閾値未満なら点を採用しない |
| 一時的な欠落（1–2f） | 直前の平滑値を保持してよいか実験で決定 |

## 4. 仮想ペン先計算

詳細は [04-VIRTUAL-PEN.md](04-VIRTUAL-PEN.md)。

概要:

1. 方式に応じて \(P_{\mathrm{pen}}\) を計算
2. 平滑化を適用
3. Canvas 座標へ写像
4. 描画 ON なら線分追加

## 5. 平滑化仕様

| モード | 式 / 概要 | 初期パラメータ案 |
|---|---|---|
| none | 生値そのまま | — |
| EMA | \(S_t=\alpha P_t+(1-\alpha)S_{t-1}\) | \(\alpha=0.3\) |
| One Euro | 速度に応じてカットオフを変える | minCutoff=1.0, beta=0.007, dCutoff=1.0 |

比較実験のため、実行中に切替可能にする。

## 6. 描画仕様

| 項目 | 仕様 |
|---|---|
| 線色 | 濃い単色（例: `#111`） |
| 線幅 | 固定（例: 3px）。ブラシは後回し |
| 合成 | 通常描画。消しゴムなし |
| ストローク | 描画ON〜OFF、または手ロストで区切る |
| ガイド線 | 半透明の水平/垂直/斜め線 |
| クリア | ユーザー軌跡のみ消去。ガイドは設定に従う |

## 7. キャリブレーション入口

ボタン押下で開始。詳細フローは [05-CALIBRATION.md](05-CALIBRATION.md)。

最低限取得するもの:

- 握り形の代表 landmark 関係
- 仮想ペン長 \(L\) の初期値
- 画面上の可動範囲に対する写像（簡易 affine / スケール＋オフセット）

## 8. エラー・権限

| ケース | 表示 |
|---|---|
| カメラ拒否 | 権限を許可する案内 |
| カメラなし | デバイス未検出 |
| MediaPipe 読込失敗 | ネットワーク / CDN 確認 |
| HTTPS/localhost 以外 | セキュアコンテキストが必要である旨 |

## 9. ログ（実験支援）

可能ならブラウザコンソール、または画面上に簡易メトリクスを出す。

記録候補:

- timestamp
- estimationMode / smoothingMode
- raw tip / smooth tip / canvas tip
- detection score / handedness
- drawingEnabled
- guideMode

後で CSV エクスポートできれば実験3・4が楽になる（Phase 3 完了後の拡張でも可）。
